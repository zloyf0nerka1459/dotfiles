# 🌌 Arch Linux Rice: i3-gaps + EWW + Picom-Pijulius

> Современное, быстрое и полностью адаптивное рисовое окружение для Arch Linux с визуальным переключателем тем в стиле Hyprdots, интерактивными панелями EWW, поддержкой Wi-Fi / Ethernet и игровым режимом с нулевой задержкой.

---

## ✨ Основные особенности

- 🎨 **Визуальный менеджер тем (`Mod + T`)**:
  - Карточная галерея в Rofi с закругленными 16:9 миниатюрами.
  - Мгновенная генерация палитры через Pywal на лету.
  - Бесшовное переключение без мерцания экранов (обои, i3, Kitty, EWW, Dunst, GTK).
  - Встроенный CLI-генератор тем: `theme-create /путь/к/картинке.jpg`.
- ⚡ **Интерактивные виджеты EWW**:
  - **Верхняя панель**: воркспейсы i3, заголовок активного окна, часы/дата с выпадающим календарем и погодой, монитор нагрузки CPU/RAM.
  - **Сетевое меню**: выпадающая карточка с подробным статусом Ethernet (IP, интерфейс, шлюз), сканером доступных Wi-Fi сетей и подключением с вводом пароля через Rofi.
  - **Нижняя панель**: полированная панель задач (taskbar) с иконками и индикацией фокуса.
- 🎮 **Игровой режим (`Mod + P`)**:
  - Мгновенное отключение Picom в один клик для максимальной плавности и 0 задержки в соревновательных играх (CS2, Apex и т.д.).
- 🖥️ **Универсальная поддержка железа**:
  - Автоматическое определение одномониторных ПК, ноутбуков и мультимониторных конфигураций.
  - Безопасная работа с картами NVIDIA, AMD Radeon и Intel.
- 🐚 **Эстетичный терминал**:
  - Шрифты **JetBrainsMono Nerd Font 11**, закругления, аккуратные отступы.
  - Минималистичный и чистый **Starship prompt** без лишнего визуального мусора.

## ⌨️ Горячие клавиши (`$mod = Super / Win`)

| Сочетание | Действие |
| :--- | :--- |
| **`Mod + Return`** | Открыть терминал **Kitty** |
| **`Mod + D`** | Меню приложений **Rofi** |
| **`Mod + T`** | Визуальный выбор темы (**Hyprdots Theme Selector**) |
| **`Mod + B`** | Веб-браузер |
| **`Mod + C`** | Менеджер буфера обмена **CopyQ** |
| **`Mod + P`** | Игровой режим (вкл/выкл композитор **Picom**) |
| **`Mod + F1`** | Шпаргалка всех хоткеев в Rofi |
| **`Print`** | Скриншот текущего экрана в буфер и файл |
| **`Shift + Print`** | Скриншот выделенной области |
| **`Mod + Shift + Q`** | Закрыть текущее окно |
| **`Mod + 1..0`** | Переключение на рабочий стол 1–10 |
| **`Mod + Shift + 1..0`** | Перенос окна на рабочий стол 1–10 |
| **`Mod + Shift + R`** | Перезагрузить i3 на лету |

## 📦 Быстрая установка

### В одну команду:
```bash
git clone https://github.com/YOUR_USERNAME/dotfiles.git ~/dotfiles
cd ~/dotfiles
./install.sh
```

Инсталлятор автоматически:
1. Проверит окружение Arch Linux и наличие AUR-хелпера (`yay` / `paru`).
2. Установит все необходимые пакеты и шрифты.
3. Создаст резервную копию твоих текущих конфигураций в `~/.config_backup_TIMESTAMP`.
4. Свяжет файлы через **GNU Stow**.
5. Применит дефолтную тему `Ghibli Serenity` (сгенерирует палитры Pywal, кэши EWW и `.fehbg`).

---

## 🎨 Создание собственной темы

Чтобы превратить любую картинку в готовую тему с палитрой и миниатюрой:
```bash
theme-create ~/Pictures/wall.jpg
```
Новая тема мгновенно появится в селекторе по **`Mod + T`**.
